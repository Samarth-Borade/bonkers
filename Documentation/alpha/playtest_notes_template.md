# BONKERS! Playtest Notes

Stenographer's sheet for live playtests. Make a copy per session (for example `playtest_1_2026-10-16.md`),
fill it in while people play, and paste the **Summary for the GDD** into the GDD's "Review Notes".

Write down what you **see and hear**, not what you think the fix is; fixes come later.
Quotes are gold: write them word for word.

## What to watch for

Tick or note each one. These map to the questions our design (and the GDD) depends on.

### The twist: does falling behind feel like it helps?
- [ ] Did the player who was behind notice they got **attacks** from ? boxes?
- [ ] Did they notice the **LEADING / CHASING** tag or the progress bar?
- [ ] Did a race swing back and forth, or did the leader run away?
- Notes:

### Levers and traps
- [ ] Did players find the levers without being told?
- [ ] Did they understand **only the chaser** can pull them?
- [ ] Did they connect a lever to its trap (same letter and color)?
- [ ] Did a trap ever catch the leader? Did it feel fair or cheap?
- Notes:

### Attacks and defence
- [ ] Were attacks dodged? Which ones always hit, which never did?
- [ ] Did players read the warnings (bomb beam, brick wall flash)?
- [ ] Did anyone use Shield / Banana / Fake Box on purpose?
- Notes:

### Levels
- [ ] Rows or hazards where people died over and over (write level + row + hazard):
- [ ] Any jump that felt impossible or unfair:
- [ ] Any spot where players got stuck or confused about where to go:
- Notes:

### Controls and feel
- [ ] Did sharing one keyboard work? Any hands-crossing or key-ghosting?
- [ ] Did a BONK ever feel like the controls' fault instead of the rival's?
